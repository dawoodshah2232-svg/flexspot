The spec sheet is nearly identical

This is Apple's easiest comparison to make, because there's almost nothing to compare. Both phones run the Apple A20 Pro (2nm) chip, both have 12GB of RAM, both carry the same 48MP Fusion main + 48MP ultra-wide + 48MP telephoto camera system with the variable-aperture main lens, both have 120Hz Super Retina XDR OLED panels, both are IP68, and both offer 256GB–2TB storage.
